Antes de `function registrar(i)`, coloque: ```js function identificarCarta(code) { if (CARTAS[code]) return CARTAS[code]; const m = code.match(/^D-([A-Z0-9_]+)-\d{4}$/); if (!m) return null; const especieId = m[1].toLowerCase(); if (!ESPECIES[especieId]) return null; return { tipo: 'pokemon', especie: especieId }; } ``` Dentro de `registrar(i)`, use: ```js const m = code.match(/D-[A-Z0-9_]+-\d{4}|[A-Z0-9]+-\d{4}/); if (m) code = m[0]; const c = identificarCarta(code); ``` E no scanner, substitua a expressão que procura o código por: ```js const m = r[0].rawValue.match( /D-[A-Z0-9_]+-\d{4}|[A-Z0-9]+-\d{4}/i ); ``` Também mude o placeholder do registro para `D-ROCKRUFF-0001`. --- **O resultado esperado:** você seleciona Rockruff, escolhe a quantidade e aperta Gerar.
